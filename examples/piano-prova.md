# Piano di prova

Un piano minimo per vedere AutoLoop all'opera consumando pochissimo: ogni blocco
chiede un piccolo file di testo. Usa come cartella di lavoro `examples/prova`.

## Saluto
Crea il file `saluto.txt` con una frase di benvenuto in italiano.

## Elenco
Crea il file `colori.md` con un elenco puntato di tre colori e, accanto a ciascuno, un oggetto di quel colore.

## Riepilogo
Crea il file `riepilogo.md` che descrive in due righe i file creati nei blocchi precedenti.
